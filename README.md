SQL for Data Analysis

This project is part of my Week 2 SQL for Data Analysis assignment. The main objective is to practice SQL fundamentals by working with a sample sales dataset and extracting useful information about customers, orders, and sales performance.

## Project Overview

The project uses a sample sales database containing order-related information such as order ID, customer name, and total price. SQL queries are used to organize, summarize, and analyze the data. The results help identify top customers, calculate overall sales, and understand average order values.

## SQL Concepts Covered

The project demonstrates the practical use of important SQL concepts, including:

* SELECT for retrieving data from the database
* WHERE for filtering records based on conditions
* GROUP BY for grouping records by customer
* ORDER BY for sorting analysis results
* COUNT() for calculating the number of orders
* SUM() for calculating total sales and customer purchases
* AVG() for calculating average order value
* Basic customer and sales analysis using aggregate functions

## Analysis Performed

The following analyses are included in the project:

1. **Top Customers:** Identifies customers based on their total purchase amount and number of orders.
2. **Average Order Value:** Calculates the average value of all orders in the dataset.
3. **Total Sales:** Calculates the overall sales generated from all recorded orders.
4. **Number of Orders:** Counts the total number of orders available in the dataset.
5. **Orders by Customer:** Groups customers and calculates how many orders each customer placed.
6. **Sales by Customer:** Calculates the total purchase amount generated by each customer and sorts customers by sales.
